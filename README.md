# Balanced_295 -  Telegram бот для записи сообщений в Google Sheets

Этот бот считывает сообщения из группы Telegram и записывает их в таблицу Google Sheets. В проекте используются API Telegram и Google Sheets.


## Настройка

### 1. Инструкция по получению "service_account.json" и настройке Console Cloud Google

1) Чтобы правильно настроить Console Cloud Google Вам необходимо выполнить каждый шаг из этой инструкции (ссылка: https://habr.com/ru/articles/778512/) -> получите service_account.json
2) Включите Google Sheets API
 - Перейдите по следующей ссылке, чтобы включить Google Sheets API для вашего проекта: https://console.developers.google.com/apis/api/sheets.googleapis.com/
 - Вы попадете на страницу API в Google Cloud Console. Нажмите на кнопку Enable (Включить), чтобы активировать API для вашего проекта.


### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта и добавьте туда ваши данные:

```env
BOT_GROUP_NAME=
BOT_TOKEN=
BOT_SHEETS_NAME=
```

- **BOT_GROUP_NAME**: имя вашей группы в Telegram, из которой бот будет считывать сообщения.
- **BOT_TOKEN**: токен вашего бота в Telegram.
- **BOT_SHEETS_NAME**: название таблицы Google Sheets, в которую будут записываться сообщения.

### 3. Подключение бота к группе Telegram

Чтобы бот мог считывать сообщения из группы Telegram, нужно добавить его в группу:

1. Перейдите в **Telegram** и создайте группу, если она еще не создана.
2. Найдите вашего бота через @BotFather и получите токен.
3. Добавьте вашего бота в группу как администратора с правами на **Чтение сообщений**.

После добавления бота в группу, он сможет считывать сообщения и записывать их в Google Sheets.

### 4. Настройка Google Sheets

1. Откройте таблицу Google Sheets, в которую будут записываться данные.
2. Нажмите **Share** (Поделиться) и добавьте "client_email" из вашего `service_account.json` как редактора таблицы.

### 5. Запуск бота

После того как вы настроите переменные окружения и получите доступ к Google Sheets и Telegram, можно запустить бота:

```bash
python bot.py
```

Бот начнёт прослушивать сообщения в группе Telegram и записывать их в указанную таблицу Google Sheets.
